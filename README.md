# DiscoverLatest 洞察運算

AI 智慧投資分析平台

## 功能

- 📊 市場總覽：台股/美股指數與熱門 ETF
- 🔍 個股分析：AI 診斷 + SMC/ICT 技術分析
- 🌐 產業圖譜：供應鏈與 Beta 連動關係
- ⭐ 自選清單：追蹤關注的標的
- 💼 投資組合：持股管理與 AI 健康度評分

## 技術架構

- Frontend: Gradio + Custom CSS
- Backend: Python + Supabase
- AI: Google Gemini (兩段式架構)
- Charts: TradingView Lightweight Charts

## 安裝

```bash
pip install -r requirements.txt
```

## 環境變數

參考 `.env.example` 設定必要的環境變數。

## 開發

本專案部署於 Hugging Face Spaces，不支援 localhost 測試。
