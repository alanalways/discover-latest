# DiscoverLatest 學生 Beta 商業化 Roadmap（暫緩）

> 狀態：目前先專注免費 Beta。這份文件保留作為未來參考，不是現在的執行主線。

## 產品定位
- 核心族群：二技護理系學生
- 主打價值：省時間、看得懂、快速整理投資功課
- 溝通語氣：不是神預測，是 AI 研究助理

## 定價草案
| 方案 | 月費 | 用途 |
|---|---:|---|
| Beta 體驗 | 0 | 開放高級功能收回饋 |
| Pro 學生方案 | NT$149 | 每日研究、完整報告、自選股 |
| Premium 重度使用 | NT$249 | 高額度、盤前盤後整理、更多追蹤 |

## 推廣策略
1. 校園社群貼文：強調「沒時間盯盤也能快速看重點」
2. LINE/Discord 社群招募：開放 Beta 名額、蒐集回饋
3. 首頁導購：先體驗、後導 Pro
4. 內容素材：每日 1~2 篇 AI 精選個股摘要做社群曝光

## 第一階段（現在）
- 重做首頁：更像商業產品，講清楚學生市場與 Beta 價值
- 重做管理後台：營運數字集中展示
- 開 Beta：free 用戶套用高級權限
- 保持人工升級流程，但明確標示只是 Beta 過渡

## 第二階段（有第一批活躍用戶後）
- 補 paywall：摘要免費、全文付費
- 加入付款流程與訂閱狀態機
- 追蹤準確率、續訂率、活躍率
- 建立每週回饋表單與產品改版節奏

## 第三階段（開始有營收後）
- 重新整理分析流程成本
- 改善資料更新頻率
- 補 CI / 測試 / 錯誤監控
- 擴充後台：漏斗、付費轉換、留存與客服紀錄
